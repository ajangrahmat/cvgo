Installation, import, and feature map

CVGO V1 pins CVGO 0.1.1, OpenCV Contrib 4.11.0.86, NumPy 1.26.4, and MediaPipe 0.10.21. Use opencv-contrib-python; do not install another OpenCV variant alongside it. MediaPipe object and gesture models download on first use and are cached afterward.

pip install cvgo

Python style and defaults

Classes use PascalCase, methods use snake_case, and constants use UPPER_CASE. Use read_fps(), not readFPS(); the short form is fps.read().

camera = go.Camera()
faces = go.FaceDetector()
landmarks = go.FaceLandmarks()
hands = go.HandTracker()
pose = go.PoseTracker()
objects = go.ObjectDetector()
arduino = go.Serial()
timer = go.Timer()

camera = go.Camera(1, width=1280, height=720)
hands = go.HandTracker(max_hands=1, detection_confidence=0.7)
pose = go.PoseTracker(model_complexity=0)
objects = go.ObjectDetector(confidence=0.7, allow=["person"])
arduino = go.Serial("COM5", baud=115200)
telegram = go.Telegram(cooldown=60)

Defaults are camera 0, one face, two hands, one pose, one holistic person with 543 landmarks, ten objects at confidence 0.5, landscape segmentation, automatic serial at 9600 baud, Telegram cooldown 30 seconds, Timer one second, and Smoother alpha 0.45.

Camera and GUI

The default backend is OpenCV CAP_ANY. Press q to quit.

camera = go.Camera()
while True:
    frame = camera.read()
    if frame is None:
        break
    if not camera.show(frame):
        break
camera.close()

Face detection, landmarks, and metrics

detector = go.FaceDetector()
faces = detector.detect(frame)
for face in faces:
    face.draw(frame)
detector.close()

landmarker = go.FaceLandmarks()
faces = landmarker.detect(frame)
if faces:
    face = faces[0]
    ear = go.eye_ratio(face)
    yaw = go.yaw_ratio(face)
    pitch = go.pitch_ratio(face)
    go.put_text(frame, f"EAR: {ear:.3f}")
    face.draw(frame)
landmarker.close()

Hand and pose tracking

tracker = go.HandTracker()
hands = tracker.detect(frame)
for hand in hands:
    hand.draw(frame)
tip = hand.point(go.HandLandmark.INDEX_FINGER_TIP)
x, y = tip.pixel(frame)
tracker.close()

pose_tracker = go.PoseTracker()
pose = pose_tracker.detect(frame)
if pose:
    pose.draw(frame)
    shoulder = pose.point(go.PoseLandmark.LEFT_SHOULDER)
    world_points = pose.world_points
pose_tracker.close()

A Hand has 21 points, handedness, confidence, box(), and raw results. Webcam labels are adjusted automatically; use mirrored=True for an already flipped frame. A pose is one visible body, not a multi-person counter.

Drowsiness and driver monitor

EAR_THRESHOLD = 0.20
eye_timer = go.Timer(1.5)
ear_smoother = go.Smoother()
alarm = go.Alarm()
faces = go.FaceLandmarks().detect(frame)
drowsy = False
if faces:
    face = faces[0]
    ear = ear_smoother.update(go.eye_ratio(face))
    drowsy = eye_timer.check(ear < EAR_THRESHOLD)
    status = "DROWSY" if drowsy else "NORMAL"
    color = (0, 0, 255) if drowsy else (0, 255, 0)
    go.put_text(frame, f"Status: {status}", color=color)
    face.draw(frame, color=color)
else:
    eye_timer.reset()
    ear_smoother.reset()
alarm.trigger(drowsy)

The complete driver workflow combines EAR, smoothing, head direction, timers, missing-face detection, Arduino bitmasks, Telegram, sound, GUI, and FPS. DriverMonitor is available as a shortcut for quick prototypes.

Telegram alerts

Create a bot with @BotFather. Store the token and chat ID in environment variables, never in source code.

# PowerShell
$env:CVGO_TELEGRAM_TOKEN="TOKEN_DARI_BOTFATHER"
$env:CVGO_TELEGRAM_CHAT_ID="CHAT_ID"

# Linux/macOS
export CVGO_TELEGRAM_TOKEN="TOKEN_DARI_BOTFATHER"
export CVGO_TELEGRAM_CHAT_ID="CHAT_ID"

telegram = go.Telegram(token="TOKEN_DARI_BOTFATHER")
print(telegram.find_chat_id())
telegram = go.Telegram()
telegram.send_message("CVGO aktif")
telegram.send_photo(frame, "Peringatan: orang terdeteksi.", key="security")
if drowsy:
    telegram.send_photo(frame, "Peringatan: pengemudi mengantuk.", key="drowsy")

send_photo() accepts OpenCV frames, bytes, or image paths. Cooldown defaults to 30 seconds; use a different key per alert or set cooldown=60. Delivery returns True/False and details are available through telegram.last_error.
